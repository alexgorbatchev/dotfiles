# scripts/typegen

Go-to-TypeScript type generator that translates `pkg/config` Go structs into TypeScript interfaces for shared dashboard and runtime usage.

## Commands

- Generate TypeScript types: `go run scripts/typegen/main.go`
- Generate types to specific output: `go run scripts/typegen/main.go -out <path>`
- Run unit tests: `go test -v ./scripts/typegen/...`

## Local conventions

- Uses `typescriptify-golang-structs` to convert `pkg/config` structs into TypeScript interfaces.
- Default output target is `packages/dashboard/src/shared/types.gen.ts`.
- Post-processes generated code to refine types to TypeScript unions where needed (e.g. `toolConfigsDir: string | string[]`).
- Automatically formats generated TypeScript output with `bun --bun oxfmt`.

## Local gotchas

- **DSL types distinction:** `scripts/typegen` translates configuration structs for the dashboard client and runtime deserialization. It does NOT generate the DSL declarations in `.dist/index.d.ts`, which are generated by `scripts/build/main.go` (`generateSchemaTypes`).
- **Struct changes:** Whenever struct definitions in `pkg/config` are added or changed, run `go run scripts/typegen/main.go` (or `just prepare`) to keep dashboard TypeScript interfaces synchronized.

## Boundaries

- Always: automatically record all new instructions in the most appropriate `AGENTS.md` file immediately upon receipt (check with user if existing instructions conflict).
- Never: publish releases automatically without explicit user authorization.
- Always: keep all unit tests in `main_test.go` passing.
- Ask first: adding new struct translations or altering union replacement mappings.
