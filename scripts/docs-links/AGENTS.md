# scripts/docs-links

Link, anchor, and sidebar reachability validation library for documentation in `.agents/skills/dotfiles/`.

## Commands

- Run docs link and anchor check: `just docs-links` (or `bun scripts/check-docs-links.ts`)
- Run unit tests: `bun test scripts/docs-links` (or `just test-ts`)

## Local conventions

- Written in TypeScript and executed via Bun.
- Validates that:
  - All relative links in `.agents/skills/dotfiles/` resolve to existing files.
  - Fragment identifiers (`#anchor`) match heading slugs generated by `GithubSlugger.ts`.
  - Every markdown document in `references/` is reachable from either `SKILL.md` or the Astro Starlight sidebar (`packages/docs/astro.config.mjs`).
- `GithubSlugger.ts` mirrors GitHub and Astro Starlight slug generation algorithms, including deduplication suffixes (`-1`, `-2`) for identical headings within a document.

## Local gotchas

- **Case sensitivity:** Anchors are verified case-sensitively against computed heading slugs because HTML element IDs are lowercased by markdown processors.
- **Reference reachability:** Adding a new markdown file under `references/` without linking to it from `SKILL.md` or `packages/docs/astro.config.mjs` will trigger a build error during `just check`.

## Boundaries

- Always: automatically record all new instructions in the most appropriate `AGENTS.md` file immediately upon receipt (check with user if existing instructions conflict).
- Never: publish releases automatically without explicit user authorization.
- Always: keep all unit tests in `scripts/docs-links/__tests__/` passing before submitting changes.
- Ask first: modifying anchor slug generation rules or sidebar configuration parsing.
